# v1.5.0-test.5 更新说明【测试】

发布日期：2026-11-03。Android 7.0+，仅 ARM64。构建号：95。

本版本通过测试通道发布，包含实验性改动，可能存在不稳定情况。

## 指令与交互

- 指令面板改为点击即执行，执行前统一弹一次确认；新增 `/workflows` 入口。
- 侧栏新增会话累计 Token 显示，方便判断长会话的消耗。
- 计划进度改为引擎推送完整步骤与真实状态，展示完成 / 进行中 / 待办；没有计划数据时保留原循环进度。
- 执行过程折叠块显示“已思考 N 段 · 使用工具 M 次”，运行中保持展开，本轮结束后自动折叠。

## 推理与上下文

- 推理强度新增“关闭”档；设置页按当前模型能力隐藏不支持的档位。
- 上下文用量面板补充消息数、主要占用、工具累计与分段 Token 明细。
- 工具结果强制紧跟发起它的 assistant 轮次，内部提示自动延后；同一 call id 的重复结果只保留第一条，孤儿结果丢弃，修复历史顺序导致的上游 400 与思考 / 文本串段。
- 思考持久化、压缩摘要、后台恢复等沿用现有行为。

## 终端与外观

- 新增终端黑 / 白双主题：全等宽字体、无阴影；黑版思考白色、输出与工具调用橙色，白版一律黑字。
- Android 原生外观页同步新增“终端 · 黑 / 终端 · 白”两档，旧的“黑白终端”偏好自动迁移到黑版。
- 终端主题不跟随系统深浅色，选择后保持固定配色。

## MCP 与更新

- 拓展页新增 MCP Server 可视化配置：新建、编辑、测试、删除；支持 stdio / http / sse。
- env 与 headers 的值保存后只显示掩码，留空表示保持原值；修改后自动热重载。
- 下载与更新源切换到 GitHub Release，并通过 gh-proxy.com 加速；正式 / 测试双通道。
- 内置更新会同时检查测试版本，并在提示中标注“【测试版】”；测试红点默认开启，可在检查更新页关闭。
- 官网与 App 内更新说明支持多版本折叠，默认只显示最新记录。

## 使用说明

- 本次仅更新测试渠道，不替换正式下载。
- 版本名 1.5.0-test.5，构建号 95，已安装较早构建的用户可覆盖升级。
- GitHub 下载链接通过 gh-proxy.com 代理；若代理不可用，可访问 GitHub Release 原地址。
